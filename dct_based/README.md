# DCT-Based GAN Fingerprint Extraction and Removal

This subproject adapts frequency-domain GAN fingerprint removal methods for
finger-vein presentation-attack images. GAN-generated images can contain recurring
spectral patterns caused by the generator's upsampling and other synthesis operations.
Because these patterns may be learned by a presentation-attack detection (PAD) model
instead of the visual characteristics of real attacks, this project tests whether
targeting the patterns can improve the use of synthetic images in PAD training.

The approach follows three attacks described by
[Wesselkamp et al.](https://doi.org/10.48550/arXiv.2205.12543): mean-spectrum,
frequency-peak, and regression-weight (LASSO) attacks. The original paper also discusses
a low-pass filtering attack; this DCT subproject focuses on the other three because
strong low-pass filtering can remove image detail along with artifacts.

## Method overview

Each image is converted to grayscale and transformed with a two-dimensional, orthonormal
discrete cosine transform (DCT). A fingerprint is estimated from genuine and
GAN-generated image collections, then used to modify the DCT coefficients of synthetic
images. The inverse DCT produces the attacked image.

### Mean-spectrum attack

The implementation computes the mean DCT coefficients for genuine and synthetic
images and takes their difference as the fingerprint:

$$
F_{\text{mean}} = \overline{D}_{\text{synthetic}} -
                  \overline{D}_{\text{genuine}}
$$

It subtracts a scaled fingerprint from each synthetic image's DCT:

$$
D_{\text{attacked}} = D_{\text{synthetic}} -
                      s F_{\text{mean}}
$$

The strength \(s\) controls the amount of modification. See
[`src_code/fingerprint.py`](src_code/fingerprint.py).

### Frequency-peak attack

This variant computes log-magnitude DCT spectra to emphasize periodic peaks, estimates
the difference between synthetic and genuine mean spectra, and converts that difference
back from the log domain. The scaled fingerprint is applied element-wise to the
original, non-log DCT coefficients. See
[`src_code/peak_fingerprint.py`](src_code/peak_fingerprint.py).

### Regression-weight attack

This variant flattens image DCTs into feature vectors and trains a LASSO regression
model to distinguish genuine from synthetic samples. The learned coefficients are
reshaped to the DCT dimensions and used as a fingerprint mask when modifying
coefficients. See [`src_code/lasso_fingerprint.py`](src_code/lasso_fingerprint.py).

## Evaluation described in the project report

The accompanying project report examines images generated by CycleGAN, DistanceGAN,
DRIT, and StarGAN variants across the PLUS, IDIAP, and SCUT finger-vein datasets. It
extracts Fourier-domain features from the first 30 frequency bands, evaluated as
low-, middle-, and higher-frequency groups (bands 1–10, 11–20, and 21–30). PAD
performance is assessed with five-fold cross-validation and metrics including APCER,
BPCER, and ACER as synthetic attack images are introduced into or substituted within
training data.

The report's main finding is that attack effectiveness depends on the dataset, GAN,
frequency band, and modification strength; there is no uniformly best attack. It
reports improvements for some IDIAP experiments when fingerprint-removal strength is
tuned, while some PLUS experiments show little ACER change for LASSO and degradation
for mean/peak attacks at higher strengths. For SCUT, the higher-frequency bands are
reported as more susceptible in some settings. Image similarity and PAD performance
also do not always move together: high SSIM can mean less visible change without
necessarily improving PAD accuracy.

## Code map

- [`src_code/fingerprint.py`](src_code/fingerprint.py) — mean-spectrum fingerprint
  estimation and removal.
- [`src_code/peak_fingerprint.py`](src_code/peak_fingerprint.py) — frequency-peak
  fingerprint estimation and removal.
- [`src_code/lasso_fingerprint.py`](src_code/lasso_fingerprint.py) — LASSO
  regression-weight fingerprint estimation and removal.
- [`src_code/knn_classifier.py`](src_code/knn_classifier.py) — evaluates PAD features
  using K-nearest neighbors and reports accuracy, APCER, BPCER, and ACER.

## Running the scripts

The scripts use hard-coded, relative dataset and output paths, so run them from this
directory and update the paths in the selected script to match your local data. Genuine
and synthetic images must have compatible dimensions because the DCT fingerprints are
combined and applied coefficient by coefficient.

Install the dependencies used by the scripts:

```bash
python -m pip install numpy scipy opencv-python tqdm scikit-learn pandas
```

Then run one of the attack scripts:

```bash
python src_code/fingerprint.py
python src_code/peak_fingerprint.py
python src_code/lasso_fingerprint.py
```

Each script's main section selects the genuine and synthetic input folders, GAN model
folders, attack output location, and (where supported) fingerprint strength. Edit
these values before running. The KNN evaluation script also expects a feature CSV path
to be configured in `src_code/knn_classifier.py`:

```bash
python src_code/knn_classifier.py
```

Review image quality as well as PAD metrics when comparing attacks; changes to
frequency coefficients can affect the visible image and the downstream classifier in
different ways.
